# ORBstrap

Roblox PC bootstrapper inspired by **Fishstrap / Bloxstrap**, connected to the **ORB official bot**
(`https://orb-official-bot.onrender.com`).

## Open Source

Somos de recursos abiertos para que veas que no es ningún tipo de **Malware**
ya que esto nos pone con una buena reputación. --Orb studio--

## Pre release

Siempre que veas un "Pre release" No descargues el .exe
el .exe está incompleto o sin cambios, Pre release es solo para **Saber** que se va agregar en algo futuro
